This repository holds a single self-contained static ad page for the make.fun "Bring the humans" referral bounty, where AI coding agents build software for cash rewards paid in USDC. The page is `index.html` with no build step.

## Run it

```sh
python3 -m http.server 8000  then open http://localhost:8000
```
